Пользовательское соглашение

ESMaps — Лесной навигатор

1. Общие положения

Настоящее соглашение регулирует использование мобильного приложения «ESMaps — Лесной навигатор» (далее — «Приложение»).

Используя Приложение, пользователь соглашается с условиями данного соглашения.

2. Лицензия

Пользователю предоставляется неисключительная, непередаваемая лицензия на использование Приложения на одном устройстве.

Каждый код активации привязывается только к одному устройству и не может одновременно использоваться на нескольких устройствах.

Пользователь может получать несколько кодов, но для активации Приложения на другом устройстве требуется новый код.

Получение нового кода для активации Приложения на другом устройстве осуществляется после новой оплаты.

Пользователь не имеет права:

  • декомпилировать, модифицировать приложение или его части

3. Функционал

Приложение предоставляет:

  • навигацию с использованием GPS
  • работу с офлайн-картами
  • дополнительные функции Pro-версии (при активации кода)

4. Ограничение ответственности

Приложение предоставляется «как есть».

Разработчик не несёт ответственности за:

  • ошибки в навигации
  • неточность карт
  • последствия использования в реальных условиях (в том числе в лесу)

Пользователь самостоятельно принимает решения на основе данных приложения.

5. Активация Pro-версии

Доступ к расширенному функционалу предоставляется после ввода кода активации.

Код:

  • предоставляется в электронном виде
  • предназначен для личного использования
  • не подлежит возврату после активации

6. Обновления

Разработчик вправе изменять функциональность приложения без предварительного уведомления.

7. Прекращение доступа

Разработчик вправе ограничить доступ к Приложению при нарушении условий соглашения.

8. Заключительные положения

Соглашение регулируется законодательством Российской Федерации.
